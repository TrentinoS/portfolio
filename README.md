# Milan Singh — Portfolio

Personal portfolio and résumé site.

**Live:** https://trentinos.github.io/portfolio/

Static site (HTML/CSS/JS), no build step. Hosted on GitHub Pages.

- `index.html` — markup (Home / Résumé / Writing)
- `styles.css` — styling, fully responsive
- `app.js` — tab routing, résumé view toggle, writing feed, PDF download
- `logos/` — company logos
